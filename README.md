# 경제 그래프 실험실

교사가 화면을 조작하고 학생이 예측·손들기·설명으로 참여하는 중학교 사회 4차시 콘텐츠입니다.

## 실행과 공유

`index.html`을 브라우저에서 열면 됩니다. 그림·스타일·프로그램을 모두 포함한 단일 파일이며, 설치나 인터넷 연결이 필요하지 않습니다.

GitHub Pages로 공유하려면 이 `index.html` 하나를 게시 대상에 올리면 됩니다. 저장소 최상위에 두거나, 기존 Pages 사이트의 하위 폴더에 넣을 수 있습니다. 빌드 명령과 외부 라이브러리는 없습니다.

## 네 차시

| 차시 | 내용 | 핵심 조작 |
| --- | --- | --- |
| 1. 곡선 도출 | 구매 의향 → 수요표·수요곡선, 판매 계획 → 공급표·공급곡선 | 1,000원부터 가격별 응답 입력, 행 선택, 그래프에 직접 좌표 선택, 점 확정, 선 연결 |
| 2. 시장균형 | 초과수요·초과공급과 가격 조정, 시장균형 | 같은 가격의 두 수량 읽기, 차이·시장 반응 따로 공개, 500원씩 가격 조정 |
| 3. 곡선 새로 쓰기 | 수요·공급의 증가·감소와 곡선 이동 | 새 수량 공개, 이전 곡선 없이 새 점·선 만들기, 완성 후 이전 곡선 겹쳐 보기 |
| 4. 새 균형 비교 | 수요·공급 변화에 따른 균형가격·균형거래량 변화 | 예측, 이전 가격의 불일치 확인, 가격 조정, 두 균형 비교 |

차시·장면 선택, 입력, 가격 변경, 점 확정, 공개, 설명, 되돌리기, 이전·다음은 오른쪽 패널에 모았습니다. 왼쪽에는 관찰용 표와 그래프를 두고, 그래프에 직접 점 위치를 선택하는 동작을 유지합니다. 각 차시·장면은 바로 선택할 수 있습니다. 공개·점·입력 상태는 장면을 오가도 유지합니다. 오른쪽 위 「수업 안내」에는 조작 방법과 모형 설명이 있습니다.

## 점 찍기

1차시 수요 그래프의 가로축 눈금 간격은 학급 인원과 관계없이 5개입니다. 축의 최댓값은 최소 30개이며, 학급 인원을 포함하는 5의 배수로 확장됩니다. 응답 수량과 점의 위치는 실제 입력값을 그대로 사용합니다.

1. 오른쪽 「점으로 옮길 가격」에서 펼쳐진 가격 버튼을 누릅니다. 각 버튼에 수량이 표시되며, 점을 찍은 가격에는 ✓가 표시됩니다. 왼쪽 표에서 선택한 행이 강조됩니다.
2. 필요하면 「수량 위치」와 「가격 높이」를 따로 공개합니다.
3. 그래프를 클릭해 좌표를 선택합니다. 수량은 정수, 가격은 1,000원 간격으로 맞춥니다.
4. 「점 확정」으로 표와 일치하는 점을 기록합니다. 잘못 고른 위치는 그대로 남겨 표와 비교할 수 있습니다.
5. 「다음 가격 선택」으로 다른 행을 골라 반복하고, 마지막에 「점 연결하기」를 누릅니다.

「표 좌표 선택」은 마우스로 정확한 위치를 고르기 어려울 때와 키보드 조작을 위한 대안입니다. 좌표를 선택하는 것과 점을 확정하는 것은 별도 조작입니다. 「점·공개 되돌리기」로 비교 → 선 → 점 순서로 되돌릴 수 있습니다.

## 자료의 구분

- 1차시 수요: 학급 인원 5~60명, 같은 아이스크림을 자기 용돈으로 한 사람당 최대 한 개 구매하는 의향입니다. 1,000원부터 5,000원까지 가격별로 인원을 입력합니다. 각 질문은 별개의 가정입니다.
- 「예시자료 사용」은 학습용 응답으로 명시됩니다. 실제 응답으로 전환하면 이전 실제 응답을 복원합니다. 응답을 바꾸면 연결된 수요 점·선은 초기화됩니다.
- 응답을 곡선 모양에 맞춰 수정하지 않습니다. 두 가격 이상 기록했다면 기록한 점들을 연결할 수 있으며, 수량이 같거나 예상과 다른 관계가 나와도 그대로 보여줍니다.
- 1차시 공급: 실제 학급 조사와 구별되는 가상 생산자의 하루 판매 계획입니다.
- 2~4차시: 별도의 공통 가상 시장을 사용합니다. 가격 1,000 / 2,000 / 3,000 / 4,000 / 5,000원에 수요량 20 / 16 / 12 / 8 / 4개, 공급량 4 / 8 / 12 / 16 / 20개입니다. 기본 균형은 3,000원·12개입니다.
- 3~4차시: 가격 이외 요인 변화로 각 가격의 수요량 또는 공급량이 4개 늘거나 줄어드는 가상 계획입니다. 다른 곡선은 일정합니다.

수량은 하루 기준의 계획입니다. 구매·판매 의향과 실제 거래량을 구분합니다. 점 사이의 선은 관계를 단순화한 표현입니다. 가격 조정 간격은 실제 시장의 속도나 경매 규칙을 재현하지 않습니다. 두 곡선이 동시에 변하는 경우는 기본 네 차시에 포함하지 않습니다.

## 두 변화 구별의 움직임

3차시 「두 변화 구별」에서 이전 점과 점선은 회색, 변화 후 점과 점선은 빨간색으로 구분합니다. 「상품 가격 변화 → 두 점 비교하기」를 누르면 빨간 점이 기존 수요 곡선 위에서 2,000원·16개에서 4,000원·8개로 이동하고, 가격축의 빨간 표시도 같은 높이로 함께 올라갑니다. 「움직임 다시 보기」로 반복할 수 있습니다. 다른 장면으로 이동하면 재생을 멈추고, 다시 돌아왔을 때는 마지막 상태를 보여줍니다.

## 진행 기록

브라우저가 허용하면 같은 기기·브라우저에서 진행 상태를 자동 저장합니다. 로컬 HTML의 저장 동작은 브라우저에 따라 다를 수 있으므로, 여러 차시에 걸쳐 사용할 때는 「수업 안내 → 기록 내려받기」로 기록을 보관할 수 있습니다. 「기록 불러오기」는 파일 형식을 확인한 뒤 네 차시의 상태를 복원합니다. 전체 초기화는 별도 확인을 거칩니다.

학생 이름·계정·연락처를 수집하거나 서버로 전송하지 않습니다. 기록에는 인원수와 교사 조작 상태가 들어갑니다.

## 공통 디자인

큰 질문, 오른쪽에 모은 교사 조작 패널, 별도의 예측·공개·다음 이동, 이전 상태 유지, 키보드 포커스와 작은 화면의 세로 배치를 사용합니다. 수요는 파랑, 공급은 자주색, 이전 곡선은 회색 점선으로 구분합니다.


## 제작 시 확인한 내용

- JavaScript 문법, 초기 화면 및 모든 장면의 렌더링.
- 점 선택과 확정의 분리, 선 연결의 별도 공개, 이전 곡선의 지연 공개.
- 초과수요·초과공급에서 기본 균형으로의 가격 조정.
- 네 가지 변화의 새 균형가격·균형거래량과 저장 기록의 형식 검증.
- 실제 브라우저에서 점·선 작성, 새 곡선과 이전 곡선 비교, 네 가지 새 균형 도달.
- 1366×768의 전체 장면 배치, 1920×1080의 투사 화면, 브라우저 오류 로그.
- 정적 ID 중복 및 외부 실행 파일·스타일·이미지 의존성이 없음을 확인.
