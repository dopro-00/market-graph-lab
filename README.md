# 경제 그래프 실험실


교사가 화면을 조작하고 학생이 예측·손들기·설명으로 참여하는 중학교 사회 수요·공급 활동입니다.

## 실행과 공유

`index.html`을 브라우저에서 열면 됩니다. 스타일과 프로그램은 HTML에 포함되어 있고 Pretendard 서체는 `assets/fonts/`에서 불러옵니다. 설치나 인터넷 연결이 필요하지 않습니다.


## 세 활동

| 상단 활동 | 세부 순서 | 핵심 조작 |
| --- | --- | --- |
| 1. 수요곡선 만들기 | 구매 의향 → 수요 점 찍기 | 가격별 응답 입력, 좌표 선택·확정, 점 연결 |
| 2. 공급곡선 만들기 | 판매 계획 → 공급 점 찍기 | 가상 판매 계획 공개, 좌표 선택·확정, 점 연결 |
| 3. 시장 균형 확인하기 | 가격 드래그·두 수량 자동 비교 → 가격 반응 예측 → 균형 확인 | 내가 그린 두 곡선의 수량·차이·균형 확인, 1,000원 단위 가격 조절 |

상단에서 활동을 고릅니다. 수요·공급 활동은 하위 순서를 선택하고, 시장은 하위 탭 없이 한 화면에서 진행합니다. 수요곡선을 완성하면 「공급곡선 만들기」로, 공급곡선을 완성하면 「시장 균형 확인하기」로 이동합니다. 상단 활동 전환은 응답이나 점을 지우지 않고 마지막 하위 순서로 돌아옵니다. 조사와 판매 계획을 모두 기록하면 주 버튼으로 점 찍기에 바로 이어집니다. 「곡선 새로 쓰기」와 「새 균형 비교」는 수업 화면에서 제거했습니다.

점 찍기는 「표에서 점 찍기 → 선 연결 → 곡선 살펴보기」 순서입니다. 표의 행이 가격 선택기이며, 그래프에서 위치를 고른 뒤 아래 주 버튼으로 점을 확정합니다. 다음 순서 이동과 결과 공개는 별도 동작입니다.

## 구매 의향 조사

「구매 의향 조사」를 누르면 모달에서 1,000원부터 5,000원까지 하나씩 조사합니다. 학급 인원은 응답 표 화면에서 설정하고, 모달에서는 구매 의향 인원만 입력한 뒤 「기록하고 다음」을 누르거나 Enter를 누릅니다. 마지막 가격을 기록하면 모달이 닫히고 응답 표가 보입니다. 닫기나 Escape로 닫아도 같은 창에서는 입력 중인 값이 유지되며, 기록한 값은 브라우저에 저장됩니다.  「조사 이어하기」로 미기록 가격부터 계속합니다. 표의 가격을 누르면 해당 응답을 수정할 수 있습니다. 입력은 0명부터 학급 인원까지의 정수이며, 실제 응답을 곡선 모양에 맞춰 바꾸지 않습니다.

## 점 찍기

수요 그래프의 가로축 눈금 간격은 학급 인원과 관계없이 5개입니다. 축의 최댓값은 최소 30개이며, 학급 인원을 포함하는 5의 배수로 확장됩니다. 응답 수량과 점의 위치는 실제 입력값을 그대로 사용합니다.

1. 표에서 점으로 옮길 가격의 행을 누릅니다. 선택한 행이 강조되고, 점을 확정한 행에는 ✓가 표시됩니다. 표의 가격 버튼은 Tab·Enter 또는 ↑·↓·Home·End 키로도 선택할 수 있습니다.
2. 그래프를 클릭해 좌표를 선택합니다. 수량은 정수, 가격은 1,000원 간격으로 맞춥니다.
3. 「이 점 확정하기」로 표와 일치하는 점을 기록합니다. 점은 가격축을 따라 해당 높이로 올라가 잠깐 멈춘 뒤, 가로로 수량 위치까지 이동해 고정됩니다. 표도 가격 칸 → 수량 칸 순서로 강조됩니다. 잘못 고른 위치는 모달에서 표의 값과 비교합니다. 「다시 선택하기」나 Escape로 닫으면 그래프에 포커스가 돌아오며, 잘못 고른 점은 비교할 수 있도록 남습니다. 이 경우 애니메이션은 재생하지 않습니다.
4. 「다음 가격 고르기」으로 다른 행을 골라 반복하고, 마지막에 「점 연결하기」를 누릅니다.

「표 좌표로 선택」은 마우스로 정확한 위치를 고르기 어려울 때와 키보드 조작을 위한 대안입니다. 좌표를 선택하는 것과 점을 확정하는 것은 별도 조작입니다. 되돌리기 버튼에는 「선 연결 되돌리기」「마지막 점 되돌리기」「다시 고르기」처럼 실제 동작이 표시됩니다. 학급 인원만 바꿀 때는 이미 확정한 점과 선을 유지합니다.

## 자료의 구분

- 수요곡선: 학급 인원 5~60명, 같은 아이스크림을 자기 용돈으로 한 사람당 최대 한 개 구매하는 의향입니다. 1,000원부터 5,000원까지 가격별로 인원을 입력합니다. 각 질문은 별개의 가정입니다.
- 「예시자료 사용」은 학습용 응답으로 명시됩니다. 실제 응답으로 전환하면 이전 실제 응답을 복원합니다. 응답을 바꾸면 연결된 수요 점·선은 초기화됩니다.
- 응답을 곡선 모양에 맞춰 수정하지 않습니다. 두 가격 이상 기록했다면 기록한 점들을 연결할 수 있으며, 수량이 같거나 예상과 다른 관계가 나와도 그대로 보여줍니다.
- 공급곡선: 실제 학급 조사와 구별되는 가상 생산자의 하루 판매 계획입니다.
- 시장 균형: 앞에서 직접 연결한 수요·공급 곡선의 점을 그대로 가져옵니다. 두 곡선을 먼저 완성해야 하며, 점 사이의 수량은 그린 선을 따라 선형 보간합니다. 공통으로 기록한 가격 범위에서만 계산하며 교차점이 여러 개이거나 없으면 그대로 표시합니다. 두 선이 겹치면 균형 구간으로 표시합니다. 슬라이더 가격은 1,000원 단위이며 균형값은 실제 교점으로 계산합니다. 균형이 선택 가격 사이에 있으면 가격을 왕복 조정하지 않고 균형 결과로 이어집니다.

수요량은 한 사람당 한 개의 구매 의향이며, 공급량은 가상 생산자의 판매 계획입니다. 구매·판매 의향과 실제 거래량을 구분합니다. 점 사이의 선은 관계를 단순화한 표현입니다. 가격 조정 간격은 실제 시장의 속도나 경매 규칙을 재현하지 않습니다.

## 진행 기록

브라우저가 허용하면 같은 기기·브라우저에서 진행 상태를 자동 저장합니다. 로컬 HTML의 저장 동작은 브라우저에 따라 다를 수 있으므로, 여러 차시에 걸쳐 사용할 때는 「수업 안내 → 기록 내려받기」로 기록을 보관할 수 있습니다. 「기록 불러오기」는 파일 형식을 확인한 뒤 응답과 활동 상태를 복원합니다. 이전 형식의 기록도 불러올 수 있으며, 제거된 활동에 저장된 위치는 수요·공급 활동으로 돌아옵니다. 같은 주소를 두 창에서 열면 기록 변경을 반영하되 각 창의 현재 화면과 조사 입력 초안은 유지합니다. 초안은 창을 새로고침하거나 닫으면 사라지므로 인원은 「기록하고 다음」으로 저장하세요. 전체 초기화는 별도 확인을 거칩니다.

학생 이름·계정·연락처를 수집하거나 서버로 전송하지 않습니다. 기록에는 인원수와 교사 조작 상태가 들어갑니다.

## 공통 디자인

큰 질문, 위쪽의 활동·세부 순서 선택, 단계별 진행 표시, 표와 그래프, 아래쪽 주 행동을 사용합니다. 점의 선택·확정과 선 연결을 분리합니다. 이전 상태 유지, 키보드 포커스와 작은 화면의 세로 배치를 지원합니다. 1번 목업의 화이트·코발트 디자인을 모든 활동과 모달에 적용했습니다. Pretendard의 굵기를 본문·제목·숫자에 맞춰 나누고, 선택한 활동은 밑줄로 표시합니다. 수요는 코발트, 공급은 적갈색, 이전 곡선은 회색 점선으로 구분합니다.


## 제작 시 확인한 내용

- JavaScript 문법, 초기 화면 및 모든 장면의 렌더링.
- 점 선택과 확정의 분리, 선 연결의 별도 공개, 이전 곡선의 지연 공개.
- 직접 그린 곡선의 교차점, 여러 균형·균형 없음·겹친 구간, 보간 수량과 가격 조정.
- 네 가지 변화의 새 균형가격·균형거래량과 저장 기록의 형식 검증.
- 실제 브라우저에서 점·선 작성, 새 곡선과 이전 곡선 비교, 네 가지 새 균형 도달.
- 1366×768의 전체 장면 배치, 1920×1080의 투사 화면, 브라우저 오류 로그.
- 정적 ID 중복을 확인했고 런타임 외부 네트워크 요청 없이 로컬 서체를 사용합니다.


## 로컬 확인

`python3 -m http.server 8000 --bind 127.0.0.1`로 실행하고 `http://127.0.0.1:8000/`에 접속합니다. 설치나 빌드가 필요하지 않습니다.

`node tests/workflow.test.cjs`로 세 활동의 이동·완료·기록 호환성, 조사 입력 검증과 실제 응답 유지, 점 찍기 동작을 확인합니다. 이전 기록의 계산도 호환성 확인을 위해 검사합니다. 화면 비교와 브라우저 확인 기록은 `design-qa.md`에 있습니다.

## 서체

[Pretendard](https://github.com/orioncactus/pretendard) v1.3.9 가변 서체를 로컬에 포함했습니다. `assets/fonts/OFL.txt`에 SIL Open Font License를 보관합니다.

## UI/UX 점검

조사·수요곡선·공급곡선·시장 균형의 실제 진행, 키보드 입력, 오류 상태, 두 창 간 기록 동기화와 작은 화면을 확인했습니다. 수정 목록과 화면 근거는 `ui-ux-review.md`에 있습니다.

점 이동은 약 1.8초이며 수요·공급에 공통 적용됩니다. 도중에 화면을 바꾸거나 되돌리면 이동을 멈추고 실제 저장 상태를 표시합니다. 운영체제의 동작 줄이기 설정에서는 즉시 점을 표시합니다.


## 시장 화면 · 선택한 세 번째 디자인

수요량·공급량을 큰 숫자로 비교하고, 가격은 그래프 오른쪽 세로 슬라이더로 1,000원씩 조절합니다. 드래그하는 동안 가격선·두 점·두 수량이 즉시 바뀝니다. 주 버튼은 가격 반응 예측 → 결과 확인 → 가격 조정으로 이어집니다. 예측·시장 반응·전체 균형은 접근성 이름을 가진 모달로 표시하며, 닫기와 Esc 모두 주 버튼으로 키보드 포커스를 돌려줍니다. 결과 공개로 그래프 위치나 높이가 변하지 않습니다. 수량은 별도 공개 버튼 없이 항상 표시합니다. 한 번의 드래그는 한 번의 되돌리기로 원래 가격과 예측 상태를 복원합니다. 마우스를 놓으면 저장하며 다른 창에도 반영됩니다. 기존 응답, 점, 선, 저장 형식은 유지합니다.

그래프는 화면의 실제 너비·높이에 맞춰 좌표를 다시 계산하므로 글자를 늘이지 않습니다. 축 눈금은 그래프 너비에 맞춰 5·10·20개 간격으로 표시합니다. 휴대전화에서도 가격 슬라이더는 오른쪽에 유지하고, 주 버튼과 겹치지 않게 배치합니다. 가격 조절은 방향키·Home·End를 지원합니다.
